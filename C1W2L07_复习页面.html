核心知识点 Key Points

1为什么需要计算图 · Why a Computation Graph

神经网络的计算分两步:前向传播 (forward pass) 算出输出/成本,反向传播 (backward pass) 算出梯度。计算图把复杂计算拆成一步步小运算,能清楚解释这两个过程为什么这样组织。

A neural network's computation is organized as a forward pass (compute the cost) followed by a backward pass (compute gradients). The computation graph explains why.

2例子:J = 3(a + bc) · The Running Example

拆成三步:u = bc → v = a + u → J = 3v

代入 a=5, b=3, c=2:u = 6 → v = 11 → J = 33
Break J(a,b,c) = 3(a + bc) into three steps: u = bc, then v = a + u, then J = 3v. With a=5, b=3, c=2 we get u=6, v=11, J=33.

3什么时候计算图有用 · When It's Useful

当有一个特别关心的输出变量需要优化时最有用——比如逻辑回归里要最小化的成本函数 J。J 就是图最右端的输出节点。

The graph is most useful when there is one distinguished output variable you want to optimize — like the cost function J in logistic regression.

4两个方向 · Two Directions ⭐

→ 从左到右 Forward

前向计算,得到 J 的值

← 从右到左 Backward

反向计算,得到导数/梯度(下一讲)

A left-to-right pass computes the value of J; a right-to-left pass is the natural way to compute derivatives — next lecture.
