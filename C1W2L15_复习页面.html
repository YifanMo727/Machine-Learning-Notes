2广播的操作 · The Broadcasting Operation

cal = A.sum(axis=0) # 按列求和 → 1×4(每种食物的总热量) percentage = 100 * A / cal.reshape(1, 4) # 4×3 除以 1×4
  • axis=0:沿列方向(竖着)求和
  • axis=1:沿行方向(横着)求和

cal 是 (1,4),A 是 (3,4),形状不同却能直接相除——这就是广播在起作用。

axis=0 sums vertically down each column; axis=1 sums horizontally. Even though cal (1,4) and A (3,4) differ in shape, Python lets you divide them directly — broadcasting.

3广播的通用规则 · The General Principle ⭐

(m,n) 矩阵与 (1,n) 行向量运算:行向量被复制 m 次匹配行数。(m,n) 矩阵与 (m,1) 列向量运算:列向量被复制 n 次匹配列数。

更一般地:只要两数组在某维度上一个是 1、另一个是 m/n,较小的那个就被复制扩展到匹配大小。

回顾 L13:Z = np.dot(w.T, X) + b —— b 是标量(1×1),被扩展成 1×m 再和 Z 相加,原理完全相同。

If one array has size 1 along a dimension and the other has size m or n, the size-1 array is virtually copied to match. This is exactly what happened with scalar b in Z = wᵀX + b back in L13.

4优点与代价 · Benefit and Caution

✅ 优点:代码极其简洁,一行完成本该需要循环的运算,底层执行同样很快。

⚠️ 代价:广播的"灵活"有时会掩盖 bug——比如不小心用了形状 (n,) 的秩为 1 的数组 (rank 1 array),导致广播出乎意料的结果。下一讲教怎么避免。
Broadcasting's flexibility is powerful but can silently produce unexpected shapes and bugs — especially with rank-1 arrays. Covered next lecture.
