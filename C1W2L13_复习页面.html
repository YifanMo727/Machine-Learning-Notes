核心知识点 Key Points

1目标 · The Goal

前向传播要对每个样本算 z⁽ⁱ⁾ = wᵀx⁽ⁱ⁾ + b 和 a⁽ⁱ⁾ = σ(z⁽ⁱ⁾),共 m 次。本讲目标:不用任何 for 循环,一次算完所有样本。

Forward propagation needs z(i) and a(i) for every example. Goal: compute all m of them without a single for loop.

2关键:利用 X 的列结构 · Use the Columns of X ⭐

X 形状 (n_x, m),每列一个样本。把所有 z 排成一行 Z(1×m),则:

Z = wᵀX + [b, b, …, b]
矩阵乘法自动拿 wᵀ 对 X 的每一列做内积——这就是当初"按列堆叠"的回报
Matrix multiplication automatically takes the inner product of w with every column of X — this is exactly why we stacked examples as columns.

3numpy 实现与广播 · The numpy Line & Broadcasting

Z = np.dot(w.T, X) + b

这里 b 只是一个实数,numpy 会自动把它扩展成 [b, b, …, b] 的 1×m 行向量再相加——这个机制叫广播 (broadcasting),后面有专门一讲。

b is just a real number; Python automatically expands it into a 1×m row vector when adding. This is called broadcasting — more on it in a later lecture.

4激活值也一次算完 · All Activations at Once

所有 a 排成一行 A(1×m),σ 作为逐元素函数同时作用于 Z 的每个元素:

A = [a⁽¹⁾, a⁽²⁾, …, a⁽ᵐ⁾] = σ(Z)

至此,m 个样本的全部预测值:两行代码,零循环:

Z = np.dot(w.T, X) + b A = sigma(Z)
Apply sigmoid elementwise to all of Z at once: A = σ(Z). All m predictions in two lines, zero loops.

5下一步 · What's Next

前向传播已向量化;下一讲把反向传播(梯度计算)也向量化,彻底告别 for 循环。

Forward propagation is now vectorized; next lecture vectorizes the gradient computation too.
