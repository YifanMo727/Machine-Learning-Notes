核心知识点 Key Points

1广播的灵活性是把双刃剑 · Flexibility Is Double-Edged

numpy 的广播和灵活形状规则让代码简洁,但也让很难察觉的 bug容易混进代码——这是 L15 结尾留下的伏笔,今天拆解。

The flexibility of numpy's broadcasting is both a strength (concise code) and a weakness (hard-to-catch bugs).

2元凶:秩为 1 的数组 · The Culprit: Rank 1 Arrays

a = np.random.randn(5) a.shape # 输出 (5,) —— 不是 (5,1),也不是 (1,5)

这种形状叫秩为 1 的数组 (rank 1 array)——既不是行向量也不是列向量。a 和它的转置 a.T 看起来一模一样,这是最容易埋雷的地方。

a = np.random.randn(5) gives shape (5,) — neither a row nor column vector. a and a.T look identical when printed, which is exactly where bugs hide.

3秩为 1 数组引发的诡异 bug · The Weird Bug

np.dot(a, a.T) # 期望得到一个矩阵…… # 实际得到:一个数(标量)!

原因:(5,) 转置后还是 (5,),numpy 不会把它当真正的行/列向量做矩阵乘法,退化成普通点积。

⚠️ 这类 bug 既不报错也不崩溃,只是默默给出错误的形状/数值,调试起来非常痛苦。
With a rank 1 array, np.dot(a, a.T) unexpectedly returns a number instead of a matrix. Such bugs don't crash — they silently produce wrong results.

4三个解决办法 · Three Fixes ⭐

① 明确指定形状

用 randn(5,1) 或 randn(1,5),不用 randn(5)

② 用 assert 检查

assert(a.shape == (5,1))
低成本 + 当文档用

③ 用 reshape 纠正

a = a.reshape(5,1)
开销很低

✗ a = np.random.randn(5) # 秩 1 数组,避免 ✓ a = np.random.randn(5, 1) # 明确列向量 ✓ a = np.random.randn(1, 5) # 明确行向量 ✓ assert(a.shape == (5, 1)) # 断言检查 ✓ a = a.reshape(5, 1) # 需要时纠正形状
Avoid rank 1 arrays — always specify (n,1) or (1,n). Use assert to document and catch shape mistakes. Use reshape to fix a rank 1 array if you end up with one; reshape is cheap.
