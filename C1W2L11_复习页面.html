核心知识点 Key Points

1什么是向量化 · What is Vectorization

向量化 = 去掉代码里的显式 for 循环,用矩阵/向量运算替代。深度学习数据集巨大,运行速度决定你等结果是 1 分钟还是 1 天,向量化是必备技能。

Vectorization is the art of getting rid of explicit for loops, replacing them with matrix/vector operations. With big datasets it decides whether you wait minutes or days.

2例子:z = wᵀx + b · The Example

# 非向量化(慢)Non-vectorized z = 0 for i in range(n_x): z += w[i] * x[i] z += b # 向量化(快)Vectorized —— 一行搞定 z = np.dot(w, x) + b # np.dot(w, x) 就是 wᵀx
Instead of looping over every component, np.dot(w, x) computes the whole inner product wᵀx in one call.

3速度实测:约 300 倍 · The Speed Demo ⭐

课程现场演示:两个 100 万维向量做内积:

≈ 1.5 ms
np.dot 向量化版本
≈ 480 ms
for 循环版本

相差约 300 倍!换算:向量化 1 分钟跑完的任务,for 循环要约 5 小时。

With two 1,000,000-dimensional vectors, np.dot takes ~1.5 ms while the for loop takes ~480 ms — about 300× slower. A 1-minute vectorized job would take ~5 hours with loops.

4为什么快:SIMD 并行 · Why It's Fast

  • CPU 和 GPU 都有 SIMD 指令 (Single Instruction, Multiple Data):一条指令同时对多个数据做同样运算
  • numpy 内置函数(np.dot 等)能利用这种并行;手写 for 循环完全用不上
  • GPU 尤其擅长 SIMD,但 CPU 也没那么差——向量化在 CPU 上同样收益巨大
Both CPUs and GPUs have SIMD instructions that process multiple data with a single instruction. Built-in numpy functions exploit this parallelism; handwritten loops don't.

5经验法则 · Rule of Thumb ⭐

只要有可能,就避免显式 for 循环。

看到循环先问:能不能用 numpy 内置函数(np.dot、np.exp…)替代?

"Whenever possible, avoid explicit for loops." Always ask whether a built-in numpy function can do the job.
