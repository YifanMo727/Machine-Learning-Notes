核心知识点 Key Points

1规模驱动进步 · Scale Drives Deep Learning Progress

深度学习的思想几十年前就有,近年才爆发的核心原因是规模 (scale)——数据规模 + 网络规模。这节课最重要的一张图:

数据越多、网络越大,性能越高;传统算法很快趋于平缓 (plateau)

要达到高性能:① 训练足够大的网络;② 投入海量数据。

Traditional algorithms plateau as data grows. Bigger networks keep improving with more data. To hit high performance you need both a large enough network and a huge amount of data.

2数据从哪来 · The Rise of Data

  • 社会数字化 (digitalization of society):手机、相机、传感器、物联网不断产生带标签数据。
  • 符号约定:m = 训练样本数量 (number of training examples)。
  • ⚠️ 小数据场景下算法排序并不确定,手工设计特征 (hand-engineered features) 可能反而赢;大型 NN 只在大数据场景稳定占优。
With small training sets, the ordering of algorithms is not well defined — skill at hand-engineering features can win. Large neural nets dominate only in the big-data regime.

3三大驱动力 · Three Drivers

📊

数据 Data

数字化带来的海量带标签数据

⚡

计算 Computation

GPU 与专用硬件让训练大网络可行

💡

算法 Algorithms

大量创新,很多是为了让网络跑得更快

Three forces drive deep learning: data, computation (GPUs, specialized hardware), and algorithmic innovation — much of which aims to make networks run faster.

4算法创新例子:Sigmoid → ReLU · Example of Algorithmic Innovation

  • Sigmoid 的问题:两端区域梯度(斜率)接近 0,参数更新极慢,梯度下降 (gradient descent) 学习速度大幅变慢。
  • ReLU 的优势:正区间梯度恒为 1,不会"梯度趋零",梯度下降快得多。
Sigmoid's gradient is nearly zero at the extremes, so learning becomes very slow. Switching to ReLU (gradient = 1 for positive inputs) makes gradient descent work much faster — a classic example of an algorithmic innovation that speeds up computation.

5快速迭代循环 · The Idea → Code → Experiment Cycle

💡 想法 Idea→ ⌨️ 代码 Code→ 🧪 实验 Experiment ↻ 实验结果启发新想法,循环往复

训练一次可能要 10 分钟、1 天甚至 1 个月。训练越快 → 迭代越快 → 能尝试的想法越多,研究与产品效率大幅提升。

Building networks is iterative. Faster training means faster iteration through the idea → code → experiment loop, so you can try many more ideas.

6未来会继续变好 · Why Optimism is Warranted

三大驱动力都还在增强:数字化数据持续增长、专用硬件越来越强、算法创新不断涌现——因此深度学习在未来多年还会持续变得更好。

All three forces — data, compute, and algorithms — are still improving, so deep learning will keep getting better for many years to come.
