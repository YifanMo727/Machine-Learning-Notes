核心知识点 Key Points

1导数 = 斜率 · Derivative = Slope

导数 (derivative) 就是函数在某一点的斜率 (slope):把变量轻推一点点,函数值变化多少。

斜率 slope = 高度变化 height / 宽度变化 width
The derivative at a point is just the slope: how much f changes when you nudge the variable a tiny bit. Slope = height / width.

2直线例子:f(a) = 3a · Straight Line Example

把 a 从 2 轻推到 2.001,f 从 6 变到 6.003 —— f 的变化是 a 的 3 倍
df(a)/da = 3   (也写作 d/da f(a) = 3)
Nudge a from 2 to 2.001: f(a) goes from 6 to 6.003. f moved up 3× as much as a, so the slope df/da = 3.

3严格定义:无穷小的推动 · Infinitesimal Nudge

0.001 只是方便理解;导数的严格定义是把 a 推动一个无穷小 (infinitesimally small) 的量,看 f 变化多少倍。直觉完全一样。

The formal definition uses an infinitesimally tiny nudge rather than 0.001, but the intuition is exactly the same.

4直线的斜率处处相同 · Same Slope Everywhere

对 f(a) = 3a:无论在 a = 2 还是 a = 5,斜率都是 3——直线的导数是常数。下一讲会看到:曲线在不同点的斜率是不同的。

For a straight line, the slope is 3 everywhere. Next lecture: for curves, the slope is different at different points.
