核心知识点 Key Points

1目标:输出一个概率 · The Goal

给定输入 x(如图片的特征向量),输出预测值:

ŷ = P(y = 1 | x)

即"给定 x,y = 1(是猫)的概率"。因为是概率,必须满足 0 ≤ ŷ ≤ 1。

Given x, we want ŷ = P(y = 1 | x) — the probability that y equals 1. A probability must lie between 0 and 1.

2参数 w 和 b · Parameters

  • w ∈ ℝn_x:权重向量 (weights),维度与 x 相同
  • b ∈ ℝ:偏置 (bias),一个实数
The parameters of logistic regression: w, an nx-dimensional weight vector, and b, a real number (the bias).

3为什么不能直接用线性输出 · Why Not wᵀx + b Alone

直接让 ŷ = wᵀx + b(线性回归)不行:

  • 结果可能 大于 1,也可能是 负数 —— 不是合法的概率 ✗
The linear output wᵀx + b can be much bigger than 1 or even negative, which makes no sense for a probability.

4解决:套上 Sigmoid · The Sigmoid Solution

记线性部分为 z = wᵀx + b,再套 sigmoid:

ŷ = σ(z) = 1 / (1 + e−z)
Sigmoid 把任意实数平滑压缩到 (0, 1) 之间,输出永远是合法概率
If z is large, e−z ≈ 0 so σ(z) ≈ 1. If z is a large negative number, σ(z) ≈ 0. And σ(0) = 0.5. The output is always a valid probability.

5符号约定:w 和 b 分开 · Keep w and b Separate

有些课程定义 x₀ = 1,把 b 并入一个参数向量 θ(θ₀ 就是 b)。本课程不用这种写法:w 和 b 分开处理,实现神经网络时更简单。

Some courses merge b into a parameter vector θ (with x₀ = 1). This course keeps w and b separate — it makes implementing neural networks easier.

6学习 = 找到好的 w 和 b · What Learning Means

训练逻辑回归,就是学习参数 w 和 b,让 ŷ 成为对 P(y = 1 | x) 的好估计。怎么衡量"好不好"?需要定义损失函数 (cost function) —— 下一讲内容。

Training means learning w and b so that ŷ becomes a good estimate of P(y = 1 | x). To do that, we need a cost function — next lecture.
