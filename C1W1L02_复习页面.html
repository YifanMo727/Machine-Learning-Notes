什么是神经网络?

What is a Neural Network? (C1W1L02)

核心知识点 Key Points

1从房价预测开始 · Housing Price Prediction

输入房屋面积 (size),预测房价 (price)。这个"面积 → 价格"的函数,就是一个最小的神经网络——单个神经元 (a single neuron)。

The simplest possible neural network: one input (house size), one output (price). This single function IS a neuron.

2ReLU 函数 · Rectified Linear Unit

拟合房价的函数先是 0(价格不会为负),之后是一条向上的直线。这种形状就是 ReLU(修正线性单元),读作 "ray-lu",是最常用的激活函数之一。

Rectify(修正)= 取 max(0, x),把负数部分"修正"为 0。

The fitted function starts at zero, then goes up as a straight line — this max(0, x) shape is called ReLU. "Rectify" just means taking the max of 0.

3堆叠神经元 · Stacking Neurons

更大的网络 = 把许多神经元像乐高积木一样堆叠起来:

面积 + 卧室数→家庭规模 family size
邮编→步行便利性 walkability
邮编 + 富裕程度→学校质量 school quality
三个中间量→房价 price
Larger networks are built by stacking many neurons together, like Lego bricks.

4隐藏单元与全连接 · Hidden Units & Dense Connections

你不需要手动设计"家庭规模、学校质量"这些中间特征——网络会自己学出来。隐藏层 (hidden layer) 的每个单元都接收所有输入特征,这叫全连接 (densely connected)。

You don't hand-design the middle features; the network figures them out. Every hidden unit connects to every input feature.

5核心思想 · The Big Idea

只要有足够多的 (x, y) 训练数据,神经网络就非常擅长学出从 x 到 y 的精确映射,这正是它在监督学习 (supervised learning) 中如此强大的原因。

Given enough training data with (x, y) pairs, neural networks are remarkably good at figuring out functions that accurately map x to y.
