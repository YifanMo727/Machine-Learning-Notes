核心知识点 Key Points

1单样本的计算图 · The Computation Graph

设两个特征 x₁, x₂,前向计算三步:

前向(灰)算出损失 L,反向(红)把导数传回参数
z = w₁x₁ + w₂x₂ + b → a = σ(z) → L = −[y·log a + (1−y)·log(1−a)]
Forward: z = w₁x₁ + w₂x₂ + b, then a = σ(z) (this is ŷ), then the loss L(a, y). We want dL/dw₁, dL/dw₂, dL/db.

2反向第一步:da · Backward Step 1

da = dL/da = −y/a + (1−y)/(1−a)
The first backward step: differentiate the loss with respect to a.

3反向第二步:dz · Backward Step 2 ⭐⭐

链式法则:dz = da · (da/dz),其中 sigmoid 的导数 da/dz = a(1−a)。两式相乘,奇迹般地化简为:

dz = a − y

预测值减真实值——整讲最重要的公式,后面所有实现都直接用它。

By the chain rule, dz = da · a(1−a), which simplifies beautifully to dz = a − y: prediction minus label. Memorize this one.

4参数的导数与更新 · Parameter Derivatives & Update

量公式
dw₁x₁ · dz
dw₂x₂ · dz
dbdz

然后做一步梯度下降:

w₁ := w₁ − α·dw₁   w₂ := w₂ − α·dw₂   b := b − α·db

注意:这是单个样本上的一次更新;m 个样本 → 下一讲。

dw₁ = x₁·dz, dw₂ = x₂·dz, db = dz; then update each parameter with learning rate α. This is for one training example — next lecture extends to m examples.
