m 个样本的梯度下降

Gradient Descent on m Examples (C1W2L10)
▶ 观看视频 Watch on YouTube

核心知识点 Key Points

1从单样本到 m 个样本 · From One Example to m

成本函数是所有样本损失的平均,所以总梯度 = 各样本梯度的平均:

J(w,b) = (1/m) Σᵢ L(a⁽ⁱ⁾, y⁽ⁱ⁾)   dJ/dw₁ = (1/m) Σᵢ dw₁⁽ⁱ⁾

做法:对每个样本算一遍上一讲的导数,再取平均。

The cost is the average loss over m examples, so the overall gradient is simply the average of the per-example gradients from last lecture.

2完整算法(一次迭代)· One Iteration ⭐

J = 0; dw1 = 0; dw2 = 0; db = 0 # 初始化累加器 accumulators for i = 1 to m: # 循环① 遍历样本 z(i) = w·x(i) + b a(i) = σ(z(i)) J += −[y(i)·log a(i) + (1−y(i))·log(1−a(i))] dz(i) = a(i) − y(i) dw1 += x1(i)·dz(i) # 循环② 特征多时也要 for dw2 += x2(i)·dz(i) db += dz(i) J /= m; dw1 /= m; dw2 /= m; db /= m # 取平均 w1 := w1 − α·dw1 # 一步梯度下降 w2 := w2 − α·dw2 b := b − α·db
  • dw1、dw2、db 是累加器 (accumulators),累积整个训练集的梯度
  • 以上只是一次迭代,要重复多次才能收敛
One pass over all m examples accumulates the gradients, then divide by m and take one gradient descent step. Repeat many iterations until convergence.

3弱点:两个 for 循环 · The Weakness ⭐

这个实现有两层显式 for 循环:外层遍历 m 个样本,内层遍历 n 个特征(这里只有 2 个特征,真实场景可能上万)。

显式 for 循环让代码非常慢——深度学习时代数据量巨大,这是致命的。

Two explicit for loops: over the m examples and over the n features. Explicit for loops make your code slow — deadly with deep-learning-scale datasets.

4解决方案预告:向量化 · The Fix: Vectorization

向量化 (vectorization) 能完全去掉显式 for 循环,大幅加速。深度学习兴起前它是"锦上添花",现在是必备技能——下一讲开始学。

Vectorization gets rid of explicit for loops entirely. It used to be a nice-to-have; in the deep learning era it's essential. Coming up next.
