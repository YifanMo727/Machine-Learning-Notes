核心知识点 Key Points

1从右到左求导 · Right-to-Left

沿用上一讲的图:u = bc → v = a + u → J = 3v(a=5, b=3, c=2 → J=33)。求导时从最右端往左,先算离 J 最近的:

dJ/dv = 3

验证:v 从 11 → 11.001,J 从 33 → 33.003,变化 3 倍 ✓

The efficient way to compute derivatives is a right-to-left pass, starting closest to the output: dJ/dv = 3.

2链式法则 · The Chain Rule ⭐⭐

求 dJ/da:a 的变化先推动 v,v 再推动 J——总效果是两段"放大倍率"相乘:

dJ/da = (dJ/dv) × (dv/da) = 3 × 1 = 3
红色箭头 = 反向传播:从 J 出发,导数一路往左"传"回去
导数链式法则计算结果
dJ/dv直接:J = 3v3
dJ/da(dJ/dv)·(dv/da) = 3 × 13
dJ/du(dJ/dv)·(dv/du) = 3 × 13
dJ/db(dJ/du)·(du/db) = 3 × c6
dJ/dc(dJ/du)·(du/dc) = 3 × b9
Chain rule: if a affects v and v affects J, then dJ/da = (dJ/dv)(dv/da). The "amplification factors" multiply along the path.

3为什么从右到左最高效 · Why It's Efficient

算好的 dJ/dv 被复用于求 dJ/da 和 dJ/du;dJ/du 又复用于 dJ/db、dJ/dc。一次反向遍历就能得到 J 对所有变量的导数,不重复计算。

dJ/dv is computed once and reused for dJ/da and dJ/du; dJ/du is reused for dJ/db and dJ/dc. One backward pass yields all derivatives.

4代码记号约定 · Notation in Code ⭐

反向传播中求的都是"最终输出 J 对某变量的导数" dJ/d(var),代码里统一简写为 dvar:

dv = 3, da = 3, du = 3, db = 6, dc = 9
In code, the derivative of the final output J with respect to variable var is just named dvar — e.g., da, db, dc.

5轻推验证 · Sanity Check

验证 db = 6:b 从 3 → 3.001,则 u: 6 → 6.002,v: 11 → 11.002,J: 33 → 33.006——J 的变化是 b 的 6 倍 ✓

Nudge b from 3 to 3.001: u becomes 6.002, v becomes 11.002, and J becomes 33.006 — J moved 6× the nudge, confirming dJ/db = 6.
