核心知识点 Key Points

1回顾:上次留下的两层循环 · Recap: The Two Loops

L10 的算法有两层循环:外层遍历 m 个样本,内层遍历 n_x 个特征。L12–L13 已经消灭了内层循环(dw 合并成向量)和前向传播的样本循环(Z = wᵀX + b)。

唯一剩下的:反向传播(算 dz、累加 dw、db)还在逐样本循环。

We've already killed the feature loop and vectorized the forward pass. What's left: the backward pass still loops over the m examples one at a time.

2向量化 dz · Vectorizing dz

单样本公式:dz⁽ⁱ⁾ = a⁽ⁱ⁾ − y⁽ⁱ⁾。把所有标签排成一行 Y = [y⁽¹⁾, …, y⁽ᵐ⁾](1×m,和 A 形状一致):

dZ = A − Y

逐元素相减,一次得到全部 m 个 dz。

Stack all labels into a 1×m row vector Y matching A's shape. Then dZ = A − Y computes all m errors in one elementwise subtraction.

3向量化 db · Vectorizing db

db = (1/m) · np.sum(dZ)

np.sum 把 dZ 的所有元素加起来,一行搞定,替代原来的逐样本累加。

db = (1/m)·np.sum(dZ) adds up all elements of dZ in one call.

4向量化 dw:矩阵乘法自动求和 · Vectorizing dw ⭐

dw = (1/m) · X · dZᵀ

X 是 (n_x, m),dZᵀ 是 (m, 1),相乘得到 (n_x, 1)。矩阵乘法的定义正好是"对应列相乘再对 m 求和",与手写累加循环做的事完全一致。

dw = (1/m)·X·dZᵀ: X (n_x × m) times dZᵀ (m × 1) gives (n_x × 1). Matrix multiplication inherently sums over the m examples — exactly what the loop used to do.

5最终成果:一次迭代,零循环 · The Payoff ⭐⭐

Z = np.dot(w.T, X) + b # 前向:1×m A = sigma(Z) # 前向:1×m dZ = A - Y # 反向:1×m dw = (1/m) * np.dot(X, dZ.T) # 反向:(n_x, 1) db = (1/m) * np.sum(dZ) # 反向:标量 w = w - alpha * dw # 参数更新 b = b - alpha * db

唯一还需要 for 循环的地方:多次迭代本身——因为每次迭代依赖上一次的结果,这个循环无法向量化。

These seven lines do exactly the same work as L10's nested loops for one iteration, with zero explicit loops over examples or features. The only remaining loop is over iterations — that can't be vectorized since each depends on the last.
