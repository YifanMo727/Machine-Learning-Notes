核心知识点 Key Points

1指导原则(重申)· The Guideline

神经网络编程守则:只要有可能,就避免显式 for 循环。本讲给出更多"循环 → numpy 一行"的改写范例。

The neural network programming guideline: whenever possible, avoid explicit for loops.

2例子一:矩阵乘向量 u = Av · Matrix × Vector

# 非向量化:两层循环 u = np.zeros((n, 1)) for i in range(n): for j in range(m): u[i] += A[i][j] * v[j] # 向量化:一行 u = np.dot(A, v)
Matrix-vector multiplication u = Av needs a double loop by hand; np.dot(A, v) does it in one line.

3例子二:逐元素运算 · Elementwise Operations

需求:对向量 v 的每个元素求 e^(vᵢ):

# 非向量化 u = np.zeros((n, 1)) for i in range(n): u[i] = math.exp(v[i]) # 向量化 u = np.exp(v)

numpy 的逐元素函数一族:

写法作用
np.exp(v)每个元素求指数
np.log(v)每个元素求对数
np.abs(v)每个元素求绝对值
np.maximum(v, 0)每个元素与 0 取大者(就是 ReLU!)
v**2  /  1/v每个元素平方 / 取倒数
numpy offers a whole family of elementwise functions — np.exp, np.log, np.abs, np.maximum(v, 0) (that's ReLU!), v**2, 1/v.

4用到逻辑回归:先消内层循环 · Kill the Inner Loop ⭐

L10 的算法有两层循环,本讲先消内层(遍历 n 个特征):把 dw1, dw2, … 合并成一个向量 dw:

dw = np.zeros((n_x, 1)) # 初始化为向量 for i in range(m): # 外层循环暂时保留 z(i) = np.dot(w.T, x(i)) + b a(i) = σ(z(i)) dz(i) = a(i) − y(i) dw += x(i) * dz(i) # ⭐ 一行替代 dw1+=…, dw2+=…, … db += dz(i) dw /= m; db /= m

dw += x(i)·dz(i) 是向量整体乘标量,一行完成全部特征的累加。进度:两层循环 → 一层循环,剩下的样本循环下一讲消灭。

Treat dw as a vector: dw += x(i)·dz(i) replaces the whole inner loop over features. Two loops → one loop; the outer loop over examples dies next lecture.
