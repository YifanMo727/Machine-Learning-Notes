核心知识点 Key Points

1我们要衡量什么 · What We Need to Measure

上一讲:ŷ = σ(wᵀx + b)。训练目标是让每个样本的预测 ŷ⁽ⁱ⁾ ≈ y⁽ⁱ⁾。需要一个函数衡量"预测得好不好"——损失函数 (loss function)。

We want ŷ⁽ⁱ⁾ ≈ y⁽ⁱ⁾ on the training set. The loss function measures how good the prediction ŷ is compared to the true label y.

2为什么不用平方误差 · Why Not Squared Error

直觉上可以用 L = ½(ŷ − y)²,但在逻辑回归里它会让优化问题变成非凸 (non-convex):

非凸:梯度下降可能困在局部最优;凸:一定能滑到全局最优
Squared error makes the optimization non-convex: gradient descent can get stuck in local optima. We want a loss that gives a convex problem with a single global optimum.

3逻辑回归的损失函数 · The Loss Function ⭐

L(ŷ, y) = −[ y·log(ŷ) + (1−y)·log(1−ŷ) ]

直觉理解,分两种情况:

若 y = 1

L = −log(ŷ)
想让损失小 → ŷ 要大(接近 1)✓

若 y = 0

L = −log(1−ŷ)
想让损失小 → ŷ 要小(接近 0)✓

If y = 1, the loss is −log ŷ, so minimizing it pushes ŷ toward 1. If y = 0, the loss is −log(1−ŷ), pushing ŷ toward 0. It behaves like squared error but keeps the problem convex.

4损失函数 vs 成本函数 · Loss vs Cost ⭐⭐

损失函数 Loss L(ŷ, y)

衡量单个训练样本的表现

成本函数 Cost J(w, b)

整个训练集上损失的平均值,衡量参数 w, b 的整体表现

J(w, b) = (1/m) Σᵢ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
= −(1/m) Σᵢ [ y⁽ⁱ⁾log ŷ⁽ⁱ⁾ + (1−y⁽ⁱ⁾)log(1−ŷ⁽ⁱ⁾) ]
The loss function measures performance on a single example; the cost function J(w, b) is the average loss over the entire training set.

5训练目标 · The Training Objective

训练 = 找到让 J(w, b) 最小的 w 和 b。方法是梯度下降 (gradient descent)——下一讲。另外,逻辑回归可以看作一个极小的神经网络。

Training means finding w, b that minimize J(w, b), using gradient descent. Logistic regression can be viewed as a very small neural network.
