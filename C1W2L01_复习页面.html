核心知识点 Key Points

1什么是二分类 · What is Binary Classification

输出 y 只有两种取值:y ∈ {0, 1}。经典例子:输入一张图片,判断是猫 (1) 还是不是猫 (0)。

逻辑回归 (logistic regression) 是处理二分类的经典算法,也是接下来几讲的主角。

Binary classification: the output y is either 0 or 1 — e.g., "cat (1) vs non-cat (0)". Logistic regression is the classic algorithm for this task.

2图片如何变成输入向量 x · Image → Feature Vector

彩色图片在计算机里 = 三个矩阵(红/绿/蓝通道的像素亮度)。把所有像素值展开 (unroll) 成一个长列向量 x:

A color image is stored as three 64×64 matrices of R, G, B pixel intensities. Unroll all values into one long feature vector x with dimension nx = 64 × 64 × 3 = 12288.

3单个样本的记号 · Notation for a Single Example

  • 一个训练样本:(x, y),其中 x ∈ ℝn_x,y ∈ {0, 1}
  • m 个训练样本:{(x⁽¹⁾, y⁽¹⁾), …, (x⁽ᵐ⁾, y⁽ᵐ⁾)}
  • 上标 (i) 表示第 i 个样本
  • 需要区分时:m_train 训练集大小、m_test 测试集大小
A single example is (x, y); superscript (i) refers to the i-th training example; m (or m_train) is the number of training examples.

4矩阵 X:样本按「列」堆叠 · Stack Examples as Columns

把每个样本 x⁽ⁱ⁾ 作为矩阵 X 的一列:

X = [ x⁽¹⁾ | x⁽²⁾ | … | x⁽ᵐ⁾ ]   X.shape = (nx, m)

⚠️ 有些课程把样本按"行"堆叠,但本课程用列堆叠——这样实现神经网络时代码更简单。

Stack each x⁽ⁱ⁾ as a column of X, so X has shape (nx, m). This column convention makes neural network implementation much easier than the row convention.

5标签矩阵 Y · The Label Matrix Y

标签同样按列堆叠:

Y = [ y⁽¹⁾, y⁽²⁾, …, y⁽ᵐ⁾ ]   Y.shape = (1, m)
Stack the labels as columns too: Y has shape (1, m). In Python: Y.shape == (1, m).
